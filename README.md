# Projeto BI — Análise de Vendas e Rentabilidade

Projeto acadêmico desenvolvido em Power BI com o objetivo de analisar o desempenho comercial, a rentabilidade dos produtos e o comportamento de clientes e regiões.

## 🎯 Objetivo

Construir um dashboard interativo para análise de vendas e rentabilidade, utilizando técnicas de tratamento, modelagem e visualização de dados.

O projeto está dividido em atividades (ACs), permitindo desenvolver as análises de forma incremental.

## 🛠️ Tecnologias utilizadas

- Power BI
- Power Query
- DAX
- GitHub
- GitHub Projects
- Base de dados Sample Superstore

## 📊 Atividades do projeto

### AC1 — Análise da Evolução de Vendas e Lucro

Análise da evolução das vendas e do lucro ao longo do período, permitindo identificar variações de desempenho e comparar os resultados entre categorias.

**Principais funcionalidades:**
- Indicadores de Vendas Totais
- Indicadores de Lucro Total
- Indicadores de Pedidos
- Indicadores de Unidades Vendidas
- Evolução mensal de Vendas x Lucro
- Comparação de Vendas x Lucro por categoria
- Filtro interativo por ano

### AC2 — Análise de Produtos e Rentabilidade

Análise aprofundada das categorias, subcategorias e produtos, relacionando vendas, lucro, margem e descontos.

**Principais funcionalidades:**
- Análise por Categoria e Subcategoria
- Ranking de produtos por Vendas
- Ranking de produtos por Lucro
- Análise do impacto dos descontos sobre o Lucro
- Indicadores de Vendas, Lucro e Margem
- Filtros interativos

### AC3 — Clientes, Segmentos e Regiões

Análise do comportamento dos clientes e do desempenho comercial entre diferentes segmentos e regiões.

**Principais funcionalidades:**
- Análise por Segmento
- Análise por Região
- Análise por Estado e Cidade
- Comparação de Vendas e Lucro
- Análise de clientes
- Filtros interativos

### Entrega Final — Dashboard Executivo e Análise Integrada

Consolidação das análises desenvolvidas nas ACs em um dashboard executivo, reunindo os principais indicadores e insights do projeto.
